# Netflix Clone 🎬

A simple Netflix Clone built using HTML and CSS.

## Features

* Netflix-inspired landing page
* Responsive design
* Hero section with background image
* Navigation bar
* Email signup form
* TV feature section
* Stylish footer
* Clean and modern UI

## Technologies Used

* HTML5
* CSS3

## Project Structure

```text
netflix-clone/
│
├── index.html
├── style.css
│
├── images/
│   ├── bg.jpg
│   ├── logo.png
│   ├── tv.png
│   ├── mobile.jpg
│   └── kids.png
│
└── videos/
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your browser.
